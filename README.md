# Go DSA - Data Structures and Algorithms in Go

This project is a development and logical continuation of [dsa-notes](https://github.com/vitsmirnov/dsa-notes) - a repository that contains some data structures and algorithms I've been creating while studying this field. It includes some of them, implemented in Go, at various stages of readiness. Some (or most) of them may be useful in competitive programming.

Currently, development is in experimental mode, and the API is not yet stable.
