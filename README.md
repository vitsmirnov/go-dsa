# Go DSA - Data Structures and Algorithms in Go

This project is a development and logical continuation of [dsa notes](https://github.com/vitsmirnov/dsa_notes) - a repository that contains some data structures and algorithms that I create while studying this field. It includes a collection of some of them, implemented in Go, at various stages of readiness.

Currently, development is in experimental mode, and the API is not yet stable.
